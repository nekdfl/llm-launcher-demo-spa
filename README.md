# LLM Launcher — demo SPA

Демо-версия веб-интерфейса **LLM Launcher** — инструмента для запуска
локальных LLM на многокарточном стенде. Сервер не нужен: данные и действия
симулируются прямо в приложении. Изменения живут до перезагрузки страницы.

## Вход

| Логин   | Пароль  |
|---------|---------|
| `admin` | `admin` |

Подойдёт и любая другая непустая пара.

## Возможности LLM Launcher

- **Inferences** — запуски моделей: создать, запустить,
  остановить, перезапустить. Стадия загрузки, занятые GPU, пиковое
  потребление VRAM и RAM, логи процесса в реальном времени.
- **Dashboard** — сводка стенда: загрузка GPU/CPU/RAM, история нагрузки,
  работающие inferences, расхождения между занятой памятью GPU и
  запущенными процессами.
- **Движки** — `llama.cpp`, `vllm` и другие, с настройкой параметров
  запуска.
- **Модели** — каталог скачанных моделей, поиск на HuggingFace с
  фильтрами и сортировкой, выбор квантизации, менеджер загрузок с
  проверкой свободного места, карточка модели с README.
- **Профили** — параметры запуска модели на движке. Начальные значения
  подбираются под модель и железо; LLM-помощник предлагает уточнения по
  описанию модели.
- **Плагины и расширения** — подключение новых движков и источников
  моделей.
- **Провайдеры** — источники моделей (HuggingFace) и их настройки.
- **Роутер** — OpenAI-совместимый API к запущенным моделям: подключается
  любой клиент. Журнал запросов.
- **Голосовой API** — распознавание и синтез речи, консоль для проверки.
- **Доступ** — пользователи, роли и API-ключи для интерфейса и роутера.
- **Настройки** — LLM-помощник, хранение истории и логов.

## Скачать

Готовые сборки — в [Releases](../../releases):

- `index.html` — один файл, открывается в браузере;
- `*.AppImage`, `*.tar.gz` — Linux x64;
- `*.exe` (portable), `*.zip` — Windows x64.

## Сборка из исходников

```bash
npm ci
npm run build:reference      # build/app/index.html
cd electron && npm ci
npm run dist:linux           # AppImage, tar.gz
npm run dist:win             # portable exe, zip
```

## CI/CD

`.github/workflows/build.yml`: на push/PR — тесты, сборка HTML, Electron
под Linux (ubuntu) и Windows (windows); артефакты в Actions. На тег `v*` —
GitHub Release с HTML, AppImage, tar.gz, exe и zip.
